Rastreo (prueba)

El navegador solo da la ubicación en páginas seguras. Abrí la app por HTTPS (la URL de Railway).

No hay permiso de ubicación. Para habilitarlo:

iPhone

  1. Ajustes → Privacidad y seguridad → Localización: que esté activada.
  2. Más abajo, en la misma lista, entrá a "Sitios web de Safari" y elegí "Al usar la app" (o "Preguntar la próxima vez"), con "Ubicación exacta" activada.
  3. Si la usás en Safari (no desde el ícono de inicio): tocá "aA" en la barra de direcciones → Configuración del sitio web → Ubicación → Permitir.
  4. Volvé a la app y tocá "Empezar".

Android (Chrome)

  1. Desde el ícono de la app: mantenelo apretado → Información de la app → Permisos → Ubicación → Permitir (y "Usar ubicación precisa").
  2. Desde Chrome: tocá el ícono a la izquierda de la dirección → Permisos → Ubicación → Permitir.
  3. Revisá también Ajustes → Ubicación (activada) y Ajustes → Aplicaciones → Chrome → Permisos → Ubicación.
  4. Volvé a la app y tocá "Empezar".
